# 🎬 Mini Editor de Vídeo

App web sencilla para editar vídeos desde el navegador.

## Qué hace
- ✂️ Recorta el vídeo (inicio y fin)
- 🎨 Aplica filtros: brillo, contraste, saturación y blanco y negro
- ⏩ Cambia la velocidad
- 🔤 Añade un título encima del vídeo
- 🏷️ Añade los logos que elijas en la esquina inferior derecha (IES Valle del Jerte, Radio Pikota, Frecuencia Maker)
- 💾 Exporta el resultado y lo descarga

## Cómo usarla
1. Pulsa **Elegir vídeo**.
2. Ajusta el recorte, los filtros y el título.
3. Pulsa **Exportar vídeo** y espera a que termine.

El vídeo no se sube a ningún servidor: todo se procesa en tu ordenador.

## Tecnología
HTML, CSS y JavaScript (Canvas y MediaRecorder). No necesita instalación.
